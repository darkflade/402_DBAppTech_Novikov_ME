### Установка зависимостей
Перед первым запуском необходимо установить библиотеки Slim через Composer. В корне папки `Task09` выполните:

```bash
composer install
```

### Запуск

1.  Откройте терминал в папке `Task09`.
2.  Запустите встроенный сервер PHP:
    ```bash
    php -S localhost:3000 -t public
    ```
3.  Откройте в браузере `http://localhost:3000`.
